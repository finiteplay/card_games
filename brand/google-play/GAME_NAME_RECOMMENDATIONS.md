# Game-name recommendations by language

This matrix separates the Play listing title, Android app/launcher name (`app_name`), and in-game board header (`game_title`) for all five games and the 31 language tags currently listed in `AppLanguages`. Play listing metadata is configured only for `en-US`, `es-ES`, and `de-DE`; those three rows are recommendations for existing listing locales. Other listing-title cells are proposals for possible future localization, not approved listing copy. Each proposed Play title is at most 30 Unicode characters.

`app_name` remains the current English-branded app label in every locale, matching the repository's branding rule. This task localizes only `game_title`. In-game titles are concise because the board header is one line and ellipsizes overflow. Non-Latin terminology evidence and sources are in the [translation guide](TRANSLATION_GUIDE.md#non-latin-market-naming-patterns). Some candidate names remain provisional and need a native card-game reviewer; examples are not keyword-volume evidence.

## Recommendations

- Keep the branded `app_name` stable (`<English game name> by FinitePlay`) unless the publisher deliberately changes its naming system. This is the launcher label; the Play listing title is a separate field.
- Put the local recognizable game name first in the listing title and preserve `FinitePlay`; the title candidates fit Play's 30-character cap.
- Use English in-game titles in Bulgarian and Ukrainian to keep the board header short; use concise local names in other locales, and put longer explanatory/category phrases in listing copy. Review at the narrowest screen width and large font scale, including RTL layouts.
- Have native reviewers validate provisional terms before using any future listing localization. This matrix is naming guidance, not translation approval.
